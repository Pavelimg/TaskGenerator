# Генератор контрольных работ из LaTeX заданий

## Установка

1. Установите Python 3.10 или новее. В Windows при установке включите пункт `Add Python to PATH`.
2. Скачайте проект и распакуйте его в любую папку.
3. Откройте терминал в папке проекта и выполните:

```text
python -m pip install -r requirements.txt
```

Внешние библиотеки Python проекту не требуются, поэтому команда только проверит файл зависимостей.

Для автоматического создания PDF дополнительно установите XeLaTeX, например в составе MiKTeX. Без XeLaTeX программа продолжит создавать готовые файлы `.tex`.

## Использование

### Запуск

В Windows дважды щёлкните `Запуск.bat`. Также программу можно запустить из терминала:

```text
python main.py
```

### Добавление заданий

Каждое задание хранится в отдельном файле `.tex` по следующей структуре:

```text
Задания/
  Название предмета/
    Название темы/
      Задание 1.tex
      Задание 2.tex
```

Программа перечитывает папки при каждом действии. После добавления задания регистрировать его отдельно не нужно.

### Формат файла задания

Последней непустой строкой укажите правильный ответ:

```latex
Найдите общее решение уравнения \(u_{tt}=a^2u_{xx}\).

\begin{enumerate}[label=\arabic*)]
    \item \(u=f(x-at)+g(x+at)\)
    \item \(u=f(x-at)\)
\end{enumerate}

% Сложность: 1
% Ответ: 1
```

Допустимы один ответ (`% Ответ: 2`), несколько ответов (`% Ответ: 1, 3`) или фрагмент LaTeX (`% Ответ: \(x=2\)`). Строка `% Сложность:` необязательна. Готовый образец находится в `Шаблоны/Шаблон задания.tex`.

### Возможности меню

1. **Выгрузить все задания по предмету** — создаёт один `.tex` с разделами по темам и ключом ответов.
2. **Создать схему контрольной работы** — задаёт количество заданий из каждой темы. Например, запись `1=3, 2=5, 3=2` выбирает 3 задания из первой темы, 5 из второй и 2 из третьей.
3. **Создать варианты по схеме** — формирует указанное количество вариантов, бланк ответов, ключи и таблицу состава.
4. **Проверить базу заданий** — находит неправильную структуру папок, пустые задания и отсутствующие ответы.

Внутри одного варианта задания не повторяются. Между разными вариантами повторения возможны.

### Результаты

Схемы сохраняются в папке `Схемы`, а созданные материалы — в папке `Результаты`. Для каждой генерации создаётся отдельная папка со следующими файлами:

- `Вариант_01.tex`, `Вариант_02.tex` и последующие варианты;
- `Ответы.tex` и `Ответы.csv`;
- `Состав_вариантов.csv` с темой и исходным файлом каждого задания;
- PDF-файлы, если пользователь выбрал сборку и XeLaTeX установлен.

### Команды для терминала

```text
python main.py validate
python main.py export --subject "Название предмета"
python main.py generate --scheme "Схемы/Предмет/КР 1.json" --variants 10
```
